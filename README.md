# Bubble Shooter Pop Operantix - Privacy Policy

Official public privacy policy documentation for the **Bubble Shooter Pop Operantix** 2D mobile game (`com.operantix.bubbleshooter`), published by **Operantix** on the Google Play Store.

## 🌐 Live Privacy Policy URL
The hosted privacy policy page can be accessed publicly via GitHub Pages at:
- **[https://operantix.github.io/Bubble-Shooter-privacy/](https://operantix.github.io/Bubble-Shooter-privacy/)**

## 📋 Document Overview
This privacy policy provides full transparency and compliance under:
- **Google Play Developer Program Policies**
- **General Data Protection Regulation (GDPR / UK GDPR)**
- **California Consumer Privacy Act (CCPA / CPRA)**
- **Children's Online Privacy Protection Act (COPPA)**

### Key Disclosures Included:
- **Data Minimization**: No personal user accounts or private databases maintained.
- **Local Storage**: All gameplay progression, high scores, and booster inventories are stored locally on user devices.
- **Third-Party Services**: Transparent disclosures for Google AdMob (GAID/Advertising ID), Google User Messaging Platform (UMP) GDPR consent management, and Google Play In-App Billing (`remove_ads_lifetime`).
- **Data Deletion & User Rights**: Instructions on resetting advertising IDs and completely erasing local game data.
